Weekly Data Quality Report

An offline Power Automate Desktop flow that checks local JSON datasets for inconsistencies and missing values, then writes a weekly data quality report, with no SharePoint or cloud services.

Power Automate DesktopJSONExcel / CSV
~80%less manual verification time

Weeklyreport, generated automatically
Step 01 · Source

Where the data came from

Local JSON files holding several datasets of different lengths.

local JSON files
Step 02 · What was messy

What I had to deal with

  • Weekly data checks were done by hand, which was slow and error-prone.
  • The datasets varied in length, so the checks couldn’t assume a fixed structure.
  • Inconsistencies and missing values had to be found record by record.
Step 03 · Applied steps

How I cleaned and modeled it

  • Read and parsed the local JSON files.
  • Looped through every record to check for anomalies and missing values.
  • Applied conditional logic to flag data quality issues.
  • Generated a summarized report, saved locally for weekly review.
Step 04 · The question

What the dashboard needed to answer

Can weekly data quality checks run automatically and offline, without relying on SharePoint or cloud services?

Step 05 · What it shows

What the data showed

  • Recurring data entry issues were identified automatically.
  • Manual verification time dropped by about 80%.
  • Weekly reports came out accurate and consistent, so time went to analyzing results instead of gathering them.
Step 06 · Data quality & limits

What to keep in mind

  • It runs locally by design, so the report is saved on one machine rather than a shared site.
